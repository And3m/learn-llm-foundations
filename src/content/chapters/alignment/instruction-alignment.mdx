Instruction alignment starts with supervised fine-tuning (SFT). SFT continues to train a pre-trained language model on instructions and their desired responses. It uses the usual next-token learning, but on a distribution of interactions that people build carefully.

<h2 id="supervised-fine-tuning">Supervised fine-tuning</h2>

$x$ is an instruction or a conversation. $y=(y_1,\ldots,y_T)$ is the target response. SFT minimizes the loss on the response tokens:

$$
\mathcal{L}_{SFT} = -\sum_{t=1}^{T}\log P_\theta(y_t \mid x,y_{<t}).
$$

The loss increases the probability of each response token, given the instruction and the response tokens before it.

The prompt tokens give the context. Usually, a mask removes them from the loss, so that the optimization is on the assistant response. Multi-turn examples teach these behaviors:

- The boundaries between roles.
- References to earlier messages.
- Corrections.
- Follow-up behavior.

SFT is stable and efficient. It also gives preference optimization a useful starting policy. But it has an imitation limit. The model learns to copy the target responses. It does not learn to compare all possible answers or to maximize a human preference directly.

<h2 id="instruction-data">Data acquisition</h2>

Instruction examples can come from these sources:

- Experts write them.
- People adapt them from existing NLP tasks.
- People collect them from real interactions, with privacy controls.
- A stronger model generates them.

A useful mix covers many task families, difficulty levels, domains, formats and conversation turns. It also covers uncertainty and correct refusals.

Each source has a cost and a risk:

| Source | Benefit | Risk |
| --- | --- | --- |
| Written by people | Good control | Expensive |
| Changed benchmarks | More coverage | Can feel artificial |
| Synthetic generation | Low cost at scale, more diverse instructions | Copies the factual errors, style habits and safety gaps of the teacher |

Filtering, deduplication, source tracking and human review decide if a large volume becomes useful supervision.

<h2 id="less-data">Fine-tuning with less data</h2>

Large pre-trained models already contain language knowledge and task knowledge. Thus, instruction tuning often needs far fewer examples than pre-training. A small set of carefully selected, diverse demonstrations can teach the interaction pattern better than a large repetitive collection.

Data-efficiency methods do these steps:

1. Start with high-quality seed examples.
2. Generate variations.
3. Select examples that cover new skills.
4. Remove repeated items or items with low confidence.

The goal is not only the smallest dataset. The goal is the best performance on old and new tasks for the labeling and training budget.

<h2 id="instruction-generalization">Instruction generalization</h2>

A model that follows instructions must find the task from new wording. It must not memorize the training prompts. Generalization becomes better when training covers many task structures and uses the same principles across them. Evaluation must hold out task families, formats and domains, not only paraphrases of examples that the model saw.

Demonstrations that conflict make the learned policy weaker. Clear role formatting, balanced coverage and examples of edge behavior help the model learn a mapping from intent to response that it can use again.

<h2 id="weak-to-strong">Weak-to-strong supervision</h2>

Models are becoming capable in domains where human supervisors cannot fully solve the problems. In these domains, direct labels can be unreliable. Weak-to-strong supervision asks this question: can feedback from a weaker judge still make a stronger model better? These methods try to make difficult outputs easier to evaluate:

- Decomposition.
- Debate.
- Checks with tools.
- Process supervision.
- Subtasks that you can verify.

> **Caution:** The main risk is that the stronger policy learns to satisfy the weak judge. It does not learn to solve the real task.

To find this gap, use independent tests, subsets with known correct answers, hostile examples and calibrated uncertainty.
