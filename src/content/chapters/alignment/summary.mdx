Alignment adds specific behavior signals after general pre-training:

- Demonstrations teach a basic response policy.
- Comparisons show relative preferences.
- Reward-based objectives or direct objectives move the model toward the preferred behavior.

<h2 id="mental-model">The chapter in one mental model</h2>

$$
\text{pre-trained model}
\xrightarrow{\text{demonstrations}} \text{instruction policy}
\xrightarrow{\text{preferences}} \text{aligned policy}
$$

Demonstrations change a pre-trained model into an instruction policy. Preferences then change it into an aligned policy.

The second step can use one of these methods:

- A reward model and reinforcement learning.
- Direct preference optimization.
- Selected synthetic feedback.

Runtime verification can also shape the response. It does not change the model weights.

<h2 id="method-guide">Signal and method guide</h2>

| Available signal | Usual method | Main limit |
| --- | --- | --- |
| Ideal responses | Supervised fine-tuning | Only copies the demonstrations |
| Chosen and rejected responses | RLHF | Complexity of the reward model and of RL |
| Preference pairs with a reference | DPO | Sensitive to the data and the reference policy |
| Written principles or model critiques | Automatic feedback | Blind spots of the evaluator can add up |
| Intermediate steps that you can verify | Process supervision | More labeling and specification work |
| Runtime checks and candidate scores | Inference-time alignment | More serving cost and latency |

<h2 id="failure-modes">Failure modes</h2>

Look for these failure modes:

- Reward hacking.
- Shallow shortcuts in the preferences.
- Loss of useful skills.
- Too many refusals.
- Behavior that is not consistent across groups.
- Disagreement between evaluators.
- Performance that fails when the distribution shifts.

A training reward that increases is not sufficient. Use independent task metrics, human review, hostile tests and monitoring after deployment.

Alignment objectives are substitutes for the behavior that a deployment really needs. Keep their assumptions and trade-offs visible.
